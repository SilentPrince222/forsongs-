# 📝 Стандарт комментариев Forsong
Версия: 1.0

> Этот документ описывает обязательные правила для всех комментариев в коде проекта. Любой код который не соответствует этому стандарту не будет принят.

---

## 🎯 Главное правило комментариев
✅ **Комментарий отвечает на вопрос ПОЧЕМУ, а не ЧТО делает код**

❌ НЕ ПИШИ:
```python
# увеличиваем счётчик на 1
counter += 1
```

✅ ПИШИ:
```python
# Делаем задержку 200мс потому что FMA API блокирует IP при больше чем 5 запросах в секунду.
# Проверено эмпирически 28.04.2026
await asyncio.sleep(0.2)
```

---

## 📋 Обязательные части каждого файла

В начале **КАЖДОГО** `.py` файла должен быть такой заголовок:

```python
"""
Модуль: download_service.py
Назначение: Управляет очередью загрузок, параллелизмом и состоянием задач.

Отвечает за:
✅ Ограничение одновременно активных загрузок
✅ Поддержка паузы/отмены/возобновления
✅ Расчёт скорости и ETA
✅ Отправка событий о прогрессе

Зависимости: Только интерфейсы и сущности из доменного слоя
Зависит от: EventBus
Зависят от этого модуля: GUI, SearchService

@since: 28.04.2026
@author: Forsong Team
"""
```

---

## 🏷️ Стандартные теги

| Тег | Назначение |
|-----|------------|
| `⚠️ ВНИМАНИЕ:` | Критически важная информация, проигнорирование приведёт к багам |
| `✅:` | Подтверждение, гарантия поведения |
| `FIXME:` | Сломанный код который срочно нужно исправить |
| `TODO:` | План на будущее. Обязательно указывай дату |
| `NOTE:` | Важная заметка для следующих разработчиков |
| `HACK:` | Временное решение, технический долг |
| `@deprecated:` | Метод устарел, будет удалён |
| `@since:` | Дата добавления |

## ✅ Примеры правильных комментариев

### Потокобезопасность:
```python
# ⚠️ ВНИМАНИЕ: Этот метод вызывается из асинхронного потока!
# НИКОГДА не делай тут прямые вызовы на GUI виджеты.
# Только отправляй события через EventBus.
```

### Обход багов внешних библиотек:
```python
# HACK: Обход бага customtkinter 5.2.0
# При быстром удалении >10 виджетов подряд происходит падение приложения
# Issue: https://github.com/TomSchimansky/CustomTkinter/issues/1872
# Удалить когда выйдет фикс
await asyncio.sleep(0.05)
```

### Неочевидные решения:
```python
# Мы не используем таймаут тут намеренно.
# Пользователь может иметь очень медленное соединение, отмена должна быть только явная.
```

### Методы:
```python
async def add_download(self, track: Track) -> str:
    """
    Добавляет трек в очередь загрузок.
    Сразу возвращает task_id, загрузка начнётся автоматически когда освободится место.

    Args:
        track: Валидная сущность трека из доменного слоя

    Returns:
        Уникальный UUID идентификатор задачи

    Публикует события:
        DownloadAddedEvent
        DownloadProgressEvent
        DownloadCompletedEvent
        DownloadErrorEvent

    Исключения:
        TrackAlreadyDownloadingError: Трек уже находится в очереди
        InvalidTrackError: Трек не имеет рабочей ссылки на скачивание
    """
```

## ❌ Категорически запрещено:
1. Комментарии которые повторяют код
2. Нецензурная лексика и личные заметки
3. Закомментированный код который не используется. Удаляй его если не нужен.
4. Ложные комментарии которые описывают поведение которого нет
5. Комментарии вида "потом поправлю" "это временно" без тега TODO и даты

---

> 🎯 Идеальный комментарий это такой, который ты будешь рад прочитать через год когда ты полностью забудешь про этот код.
